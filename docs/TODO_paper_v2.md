## P1 — 决定性实验:HGKV 到底有没有用

这是整篇论文的存亡点。若 HGKV 在闭环上确实无贡献,则它在方法叙事中的地位必须
从"核心组件"降为"离线标签工具"(即 `frozen_selector.tex` 的叙事),或者按 P2 修好。

**设计**:同批、同时间窗、多轮(≥3),四臂:

| 臂 | 说明 |
|---|---|
| frozen + Recent-4 | 基线 |
| frozen + selector | 无适配器 |
| HGKV + Recent-4 | 只有适配器 |
| HGKV + selector | 完整 \method{} |

## P2 — HGKV 训练方式的三个可疑点(用户诊断,按嫌疑排序)

HGKV 改变的是"GUI-Owl **怎样使用**历史图片",理论上应当有用。现在不起作用,
候选原因:

### (a) 训练与部署的 k 不匹配 ← **嫌疑最大**

训练只教了 **k=1**:用**一张**远端帧替换 **最老的那个** recent 槽位。
而部署时 selector 组合 exact-B 集合,论文自己报告:**B=4 时 26% 的状态把整个
recent 窗口全换掉(k=4)**,只有 19% 保持全 recent。

**训练从未见过 k≥2,更没见过"替换非最老槽位"。** 适配器学到的是一个很窄的干预
形态,与 selector 实际产生的分配严重错配。

验证方式(便宜,离线):按部署实际产生的 k 分布,统计"k=1 的状态"与"k≥2 的状态"
上 HGKV 的 DiD 选择效应是否有差异。若 k≥2 上效应消失,即坐实。

修法:训练语料补 k=2/3/4 的替换组,且替换槽位随机化(不固定最老)。

### (b) LoRA rank 太小

当前 r=8、α=16。相对 4096 维隐层,秩 8 的 K/V 残差表达力可能不足以编码
"这张历史图该被怎样读"。

修法:r=32/64 对照,同一门控与 DiD 目标。成本:重训 + 离线门控,数小时。

### (c) 只挂 last 8 层

信息在浅层就被路由了,只改最后 8 层可能太晚。已有一次 last-36 的尝试
(`desktop_did_v5_gated36_*`),离线选择性更好但闭环仍无差别——不过那次是与
门控/无门控对照,**没有与 frozen+selector 直接同批比过**。

修法:并入 P1 的多臂对照,把 last-36 也放进去。

**优先级:(a) > (b) ≈ (c)。** (a) 有直接证据(26% 的 k=4)、验证便宜、且能解释
"为什么离线门控全过但闭环没有"。

## P3 — OSWorld 改用 max_steps=50

**决定**:以后 OSWorld 以 **50 步**为主设定(对齐 GUI-Owl-1.5-8B-thinking 的口径)。

**缺口**:我们有 selector@50 = **34.07%**(全量 361,全 H200),
但**没有 Recent-4@50**。现有的 recent 臂只跑过 15 步和 30 步。

**动作**:补 Recent-4 @50 全量,且**与 selector@50 同批**(旧的 selector@50 是
7 月 31 日跑的,跨轮不可比,建议两臂一起重跑)。成本:2 臂 × 361 × 50 步。

顺带:15/30/50/100 的 selector 曲线是 34.07 / 35.46 / 34.07 / 35.18
(全量,`osworld_sel30_clean_v1`),**在 6.7 倍预算跨度内只浮动 1.4pp**。

## P4 — 主实验预算改用 B=2

**证据**:oracle 相对 recent 锚的可提升空间在 **B=2 是 +0.102**、**B=4 只剩 +0.037**
(`indomain_gap_v1/ROOT_CAUSE.md`)。补充材料的全量预算表也显示总体峰值在 B=2
(+6.8pp)、memory-critical 峰值在 B=4(+8.6pp)。

**B=4 是最难展示选择价值的工作点**:四张 recent 帧已经覆盖了大部分需要的信息。

**动作**:主实验改 B=2 需要重跑 MobileWorld 与 OSWorld 的主对照
(Recent-2 vs selector@B=2)。**建议合并进 P1 的多臂设计**,一次跑完
B=2 与 B=4 两个预算,避免重复占机。

## 约束与已知事实(避免重复踩)

1. **效用级指标只用于 development**(用户裁定):`replay_gain`、`top1-regret`
   可做模型选择与调试,**不进主结果、不对外声称**。
2. **OSWorld 单轮口径无法分辨 ±4pp**:两个在 98% 的步上动作相同的臂,
   任务级翻转 14.4%。任何单轮 ±4pp 内的差异都不构成证据。
3. **跨轮比较不可信**:同一 Recent-4 臂三个时间窗 32.96 / 30.47 / 29.92。
   所有对照必须同批。
4. **selector 部署侧曾有校准缺陷**(readout 塔缺席 = 常数偏置,预测 100% 为负),
   已用 `--selector-score-offset` 修正;任何阈值/早停判据依赖它。
5. **30 步的 46.7/42.4 是错的**(未跑完的中期数),全量为 35.46/36.01。
   见 `paper/AUDIT_camera_ready_osworld30.md`。
