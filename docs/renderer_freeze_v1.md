# Renderer 冻结:official-style sparse multiturn

状态:`FROZEN`。日期 2026-07-26。此后全部语料生成、full-layer LoRA 训练与 selector
标签**只使用** `official_style_sparse_multiturn`(`code/causalcache/policy/gui_owl_sparse_multiturn.py`)。

## 1. 决定

单轮 renderer(`sparse_single_turn`)退出最终方法。

## 2. 预注册规则被推翻的经过 —— 以及为什么这不算事后挑数

Gate 1 的预注册冻结条件是**两条同时成立**:

```
S_multi - R_multi > 0          且      S_multi - N0 > S_single - N0
```

实测第二条满足(+0.0288 > +0.0128),**第一条不满足**(+0.0027,CI 跨零)。严格执行
预注册规则应当保留单轮,当时的处理是记录为"暂缓",并把决定权交给 Gate 3。

推翻它的不是"换个统计口径重算",而是 Gate 3 测出了一个**当初写规则时没有测量的量**:
`recent_over_b0 = Q(Recent_B) - Q(空历史)`。预注册规则隐含假设"两种格式下 Recent 都是
一个合理基线",于是把 `S - R > 0` 当成"选择有价值"的标志。该假设在单轮下是错的。

## 3. 决定性证据(Gate 3,60 组 dev,冻结 policy)

| 量 | 多轮 | 单轮 |
|---|---|---|
| `recent_over_b0_b1` | **+0.0272** [+0.0124, +0.0407] * | −0.0077 [−0.0302, +0.0130] |
| `recent_over_b0_b2` | **+0.0227** [+0.0101, +0.0346] * | **−0.0615** [−0.0914, −0.0336] * |
| `recent_over_b0_b4` | **+0.0136** [+0.0003, +0.0256] * | −0.0145 [−0.0356, +0.0058] |
| `random_gain_b1` | −0.0024(跨零) | **+0.0254** * |
| `random_gain_b2` | +0.0001(跨零) | **+0.0616** * |
| `random_gain_b4` | +0.0009(跨零) | **+0.0294** * |

读法:

1. **单轮格式下,给模型最近的历史帧比什么都不给还差**(B=2 时显著负 −0.0615)。
   多轮格式下历史确实有用(三个预算全部显著为正)。
2. 于是单轮的 `random_gain` 全部显著为正 —— **随机选帧也能赢 Recent**。多轮下
   `random_gain` 三个预算全部跨零。

**随机选帧在好格式下赢不了 Recent、在坏格式下能赢,那赢的不是选点,是格式。**

这解释了 Gate 1 的 `sparse_gain_single = +0.0335`:它不是"冻结模型已有可利用的稀疏
选点优势",而是"Recent 在单轮下是病态基线"。同一个数在多轮下归零(+0.0027,CI 跨零,
K=1/2/3/4 无一显著),因为多轮下 Recent 不再病态。

## 4. 需要的机制是三者同时成立

```
历史本身有用          recent_over_b0 > 0      仅多轮成立
随机选择不能替代       random_gain ≈ 0         仅多轮成立
正确选择仍有额外价值    cross-fit oracle > Recent   两种格式都成立
```

第三条在两种格式下都成立,所以**单独看它无法区分格式**。前两条才是判据,而它们一致
指向多轮。

## 5. 连带后果

- `docs/did_confirmation.md` 的 s50 checkpoint 是在**单轮**下训练与验收的。它证明的是
  **RA-aware DiD 目标能阻止 common-mode amplification**,不是最终 checkpoint。
  换 renderer 后 `S0/R0/SA/RA` 四臂全变,**必须重训**。
- 换格式后 `S0 - R0 ≈ 0`,adapter 要学的东西从"放大一个已存在的 +0.0335 优势"变成
  "在 ≈0 的基线上创造优势"。难度不同,**不能假定单轮结论会平移**。
- v5 五臂语料是单轮渲染的,不能直接用于新训练。
