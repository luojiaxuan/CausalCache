# Gate 3 补充审计:Recent-anchored 替换的穷举判定

日期 2026-07-26。**60 组 dev**(与 Gate 3 同一分层子样本),冻结 GUI-Owl,
`official_style_sparse_multiturn`,9,064 次新前向。CI 为 episode-cluster bootstrap
(10,000 次重采样)。产物 `/data/artifacts/causalcache-replacement-v1/marginal_final.json`。

## 0. 这次审计补了什么

Gate 3 的 beam 从空集起步,只把"丢最老那张 recent"这一支 k=1 穷举完了(实测 748/748),
k=2 覆盖率仅 6%、"丢中间/最新 recent"仅 14%。三个集合族因此被补齐到 100%:

| 族 | 内容 |
|---|---|
| `k1_drop{0..3}` | 四个丢弃位置 × 全部旧帧 |
| `k2_recent_tail` | Recent-2 + **穷举全部旧图对** |
| `b2_all_pairs` | 全部 `C(n,2)`,给 B=2 一个无偏 pool mean |

k=2 刻意不走"按 singleton 效用取 top-8"的捷径:互补性的定义就是"两张单独都不突出、
合起来才有用",按单帧效用预筛会结构性排除这类组合,等于用偏向零假设的搜索检验备择假设。

## 1. 判定一:k=2 出局

```
marginal_k2_over_k1                      -0.00729 [-0.01845, +0.00390]
selection_over_poolmean_k2_recent_tail   +0.00449 [-0.00123, +0.01046]
```

第二张旧图既没有相对第一张的正边际(点估计为负),其内部选择也不携带显著信息。
**主方法定为 k ∈ {0,1}**,不需要 set-conditioned selector。不补 k=3 —— 那条线的前提是
k=2 先赢。省下的算力:全穷举 k=2 标签需 721,618 次前向(两台 16 卡 17.2 小时)。

## 2. 判定二:动作空间宽窄,60 组分辨不了

```
selection_over_poolmean_k1_any_drop      +0.00917 [-0.00063, +0.01964]
selection_over_poolmean_k1_drop_oldest   +0.00330 [-0.00152, +0.00832]
widen_drop_position (配对差)              +0.00610 [-0.00480, +0.01780]
```

**必须注意**:"宽空间接近显著、窄空间不显著"**不等于**"宽显著优于窄"。直接配对检验
`widen_drop_position` 跨零。这是典型的 *difference between significant and non-significant
is not itself significant* 陷阱,这里显式记下以免后续被当成已证结论。

工程处置:`generate_replacement_labels.py` 的 `--k1-drop-positions` 默认取窄,放宽必须显式
指定 —— 没有证据时不该让 selector 的动作空间大 B 倍。

## 3. 判定三:选择的价值在 B=1 与 B>=2 之间有一个台阶

**本节此前的版本写的是"随预算单调衰减",那是错的,已撤回。** 撤回原因见 §3.3。

### 3.1 口径匹配的比较

`selection_over_poolmean` **依赖池的组成** —— 它是 cross-fit 增益减去池均值差,池里塞进
越多差集合、池均值越低、这个量就越大。所以跨预算比较必须让池是**同一个关于历史的
函数**在各预算上求值。

这里取 k=1 族:`Recent-(B-1)` + 一张旧图。它在每个预算下都是穷举的(实测三个预算
覆盖率均 100%),而且正好是标签生成实际使用的那个族。

| B | selection_over_poolmean(k=1 族) |
|---|---|
| 1 | **+0.01191 [+0.00373, +0.02016]** ✅ |
| 2 | +0.00168 [-0.00430, +0.00766] |
| 4 | +0.00330 [-0.00152, +0.00832] |

配对差(同一组两预算相减,消掉组间方差):

```
d1 - d2  +0.01023 [+0.00198, +0.01871]  显著
d2 - d4  -0.00162 [-0.00920, +0.00538]
d1 - d4  +0.00861 [-0.00120, +0.01826]  临界
```

**结论:B=1 显著高于 B=2;B=2 与 B=4 之间分辨不出,两者都与零分辨不出。**
不是单调衰减,是一个台阶。机制上说得通:B=1 时"替换一张"就是"唯一那张图选哪张",
选择空间即全部;B>=2 时保留了至少一张 recent、只换一张,增量消失。

### 3.2 但 B=2 的信号存在于 k=2,不在 k=1

把 B=2 的两个动作族并排看:

| 预算 | k=1 的选择效应 | k=2 的选择效应 |
|---|---|---|
| B=1 | **+0.0119** ✅ | 不存在(k<=B) |
| B=2 | +0.0017 ✗ | **+0.0080 [+0.00154, +0.01463]** ✅ |
| B=4 | +0.0033 ✗ | +0.0045 ✗ |

B=2 上 k=2 的组成效应是显著负的(-0.01233 [-0.01881, -0.00620]),即"丢掉两张 recent
换两张旧图"平均而言明显更差;但族内挑对了能找回 +0.0080。净值 `U_k2 = -0.0043` 仍为负。

**因此 §1 的"k=2 出局"只在 B=4 成立,不能外推到 B=2。** 工程判据(delta=0.005)在两个
预算上的落点不同:

```
B=4:  marginal_k2_over_k1 = -0.00729 [-0.01845, +0.00390]   CI 上界 < delta  -> NO-GO 成立
B=2:  marginal_k2_over_k1 = -0.00554 [-0.01705, +0.00611]   CI 上界 > delta  -> 未定
```

`generate_replacement_labels.py` 的 `--k2-top-n` 默认 0 是把一个 B=4 的结论硬编码成了
全局默认,这个默认值在 B=2 上会**恰好避开唯一有信号的动作族**。

### 3.3 撤回记录:三次同形态的错误

本节此前基于下表声称"选择价值随预算单调衰减":

| B | 旧表引用的数 |
|---|---|
| 1 | +0.01132 * |
| 2 | +0.00991 * |
| 4 | +0.00126 |

这三个数**来自不同的池定义**:B=4 用的是 Gate 3 的 beam 池(约 82 个精选高 Q 集合),
池均值高、减出来的选择效应小;B=1/2 用的是穷举池,含大量差集合、池均值低、选择效应大。
换成全部 `C(n,B)` 池后顺序反转(+0.0113 / +0.0132 / +0.0169),换成 k=1 族后变成台阶。
**三种池定义给出三种"趋势",说明原来那个趋势是池的性质,不是预算的性质。**

同一形态的错误在本轮出现三次:

1. 在 59/60 覆盖率的池上读 `selection_over_poolmean_k1_any_drop` 的显著性(最后一组落地后跨零);
2. 把 beam 搜索空间里各 k 的**可得数量**当成各 k 的**优劣**(富集比实测仅 0.91-1.19);
3. 本节 —— 跨池定义比较 `selection_over_poolmean`。

共同点:**拿覆盖率或池定义不同的两个量直接比大小**。规则化为:任何跨条件比较,
先证明两侧的池是同一构造规则在两个条件上求值,否则只报单侧点估计。

## 4. 组成效应与选择效应的分解

`U_k` 混了两件政策含义相反的东西,分开看:

| 族 | poolgap(组成效应) | selection_over_poolmean(选择效应) |
|---|---|---|
| `k1_any_drop` | −0.00144 | +0.00917 |
| `k1_drop_oldest` | −0.00166 | +0.00330 |
| `k2_recent_tail` | −0.00405 | +0.00449 |

三个族的 poolgap 都是负的:**随机替换比 Recent 略差**。所以方法要成立必须靠选择效应,
而不是"把旧图塞进去本身有用"。这与格式层的结论同构(历史有用 / 随机没用 / 正确选择
才有额外价值)—— 两处都是先证明基线合理,再证明选择本身携带信息。

## 5. top-N 预筛的实测召回率

标签生成阶段无法全穷举 k=2,退路是按 singleton 效用取 top-N。该近似的代价是**实测**的:

```
top-8  召回 76.7% (92/120)
top-12 召回 90.0% (108/120)
```

即 top-8 会漏掉约 1/4 的穷举最优对。因 k=2 已出局,这两个数当前不影响主线,
保留作为"若将来重开 k≥2 需要多大预筛"的定标。

## 6. 过程记录:一次过早的显著性结论

在覆盖率 59/60 时 `selection_over_poolmean_k1_any_drop` 为 **+0.01042 [+0.00104, +0.02046]**,
曾被报告为"显著"。最后一组数据落地后变为 **+0.00917 [−0.00063, +0.01964]**,CI 跨零。

记下来是因为这类错误有固定形态:**在一个尚未跑完的池上读 argmax 类统计量**。
池还在增长时,cross-fit 增益既可能升(找到更好集合)也可能降(选择噪声变大),
方向不可预判。规则:覆盖率未达 100% 前,只报点估计的趋势,不报显著性。
