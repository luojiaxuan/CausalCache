\begin{abstract}
Long-horizon GUI agents keep compressed textual summaries of past events and a
bounded number of history screenshots. At each decision the practical question
is not whether archived screenshots help in general, but how to spend the
\emph{next} high-fidelity visual slot: extend the contiguous recent window,
restore one archived non-local event, or stop adding images. We introduce
\method, which estimates the \emph{conditional marginal utility} of restoring
each archived event given the textual summaries, the current screen, and a
variable amount of already-provided recent visual context
$r\in\{0,1,2,4,8\}$. Under a matched one-image budget, \method{} restores a
non-local screenshot only when doing so is more useful than extending the
recent window. Its history-gated key/value (\hgkv) adapter adds low-rank
residuals only to restored history-image tokens and is structurally bypassed
with no history image, exactly preserving the frozen policy. It is trained with
a difference-in-differences objective whose per-arm frozen anchors make
``amplify any history image'' worth exactly zero. On 969 desktop decision
groups built from successful AgentNet trajectories, the frozen policy shows no
reliable preference for the target-relevant archived frame over the true
previous frame ($+0.001$ nats/token, $95\%$ CI $[-0.024,+0.025]$): selectivity
is not inherited. \hgkv{} creates it, with a selective DiD gain of
$+0.010$ $[+0.006,+0.014]$ against the informative previous-frame control
(and $+0.011$ $[+0.007,+0.015]$ against a redundant duplicate control) within
a pre-registered drift envelope, while a full-layer LoRA control attains
selectivity only by drifting beyond it. A budget-aware selector trained across $r$ then decides among
STOP, next-recent, and archived candidates.

\section{Introduction}

GUI agents accumulate screenshots, actions, text arguments, coordinates, and
interface changes over many decisions. Retaining every screenshot is expensive
and can distract a multimodal policy; text-only trajectories discard toggle
state, layout, transient values, and spatial correspondence. A practical agent
must therefore decide which historical events remain available in high fidelity
\citep{lu2025guiodyssey,zeng2026mementogui,shi2026androtmem}.

Most memory controllers frame this as unconditional selection: retain recent
events, retrieve visually similar screenshots, or learn salience from task
supervision \citep{zeng2026mementogui,shi2026androtmem,liu2026atmem}. Two
things are missing from that framing. First, the value of an archived
screenshot depends on what visual context is already present: with no recent
images a restored old frame may lack local grounding, while with a saturated
recent window any additional image may be redundant. Second, the action policy
must actually consume restored evidence; our experiments show that a strong
frozen policy can respond to the \emph{presence} of history images without
being reliably sensitive to their \emph{content}, in which case a better
selector has nothing to improve.

\method{} therefore poses the memory question conditionally. Given the goal,
complete textual action summaries, the current screen, and $r$ recent
screenshots, one additional high-fidelity slot may be spent three ways: not at
all (STOP), on the next contiguous recent frame, or on one archived non-local
event. The scientific quantity is the \emph{restoration advantage}
$\grestore(r)$: how much the best archived event beats the next recent frame,
as a function of $r$. Two opposing mechanisms make this genuinely empirical.
When $r$ is small, archived frames may lack local support; when $r$ is
moderate, the recent window already carries the operating context and a
non-local key fact is most complementary; when $r$ is large, either redundancy
inflates the relative value of one archived frame or saturation drives all
marginals toward zero. None of this can be assumed in advance, so we measure
$r\in\{0,1,2,4,8\}$ and treat $r{=}4$ as the primary deployment-like setting.

Learning to \emph{use} restored evidence must not corrupt the base agent.
Full-layer adaptation simultaneously changes current-screen understanding,
action syntax, and grounding; we show empirically that it gains selectivity
while drifting beyond a pre-registered envelope on recent-only and
wrong-history prompts. \method{} instead trains a history-gated KV interface
(\hgkv) that touches only restored history-image tokens and is structurally
bypassed at zero budget, with a difference-in-differences (DiD) objective in
which every arm is anchored to its own frozen score: uniform amplification of
any history cancels exactly, and only \emph{selective} use of target-relevant
content reduces the loss.

Our contributions are:
\begin{itemize}
    \item a conditional formulation of GUI visual memory: one extra
    high-fidelity slot, three actions (STOP, next-recent, restore), and the
    restoration advantage $\grestore(r)$ measured across
    $r\in\{0,1,2,4,8\}$ under matched image budgets;
    \item a policy-preserving \hgkv{} interface trained with per-arm-anchored
    DiD supervision, with exact no-history parity and pre-registered caps on
    recent-only and wrong-history drift;
    \item matched structural controls showing that full-layer adaptation
    attains selectivity only outside the drift envelope, and that token gating
    adds selective gain beyond a layer- and rank-matched ungated control;
    \item an $r$-aware budgeted selector that predicts
    $\widehat{\dsparse}(j\mid \ctx{r})$ against
    $\widehat{\drecent}(r)$ and STOP, trained on desktop data only and
    evaluated zero-shot on mobile and desktop benchmarks.
\end{itemize}

\section{Related Work}

\paragraph{Visual GUI agents and benchmarks.}
Screenshot-based GUI agents increasingly learn grounding and action prediction
directly from pixels, including CogAgent, SeeClick, ShowUI, and GUI-Owl
\citep{hong2024cogagent,cheng2024seeclick,lin2025showui,xu2026mobileagent35}.
AndroidWorld provides dynamically instantiated mobile tasks with executable
success checks \citep{rawles2025androidworld}, and OSWorld evaluates agents in
real desktop applications \citep{xie2024osworld}. GUI-Odyssey supplies
cross-application mobile trajectories \citep{lu2025guiodyssey}; our early
mobile experiments on it motivated the conditional formulation used here. We
use GUI-Owl-1.5-8B as the frozen cross-platform base policy
\citep{xu2026mobileagent35}, train on desktop trajectories from AgentNet-style
successful demonstrations, and evaluate zero-shot on held-out desktop tasks and
a cross-app mobile memory benchmark. \pending{Cite the MobileWorld benchmark
report once its canonical reference is fixed.}

\paragraph{Long-horizon GUI memory.}
GUI-Odyssey couples cross-app trajectories with a history resampler that attends
to prior screenshots \citep{lu2025guiodyssey}. MementoGUI learns multimodal
memory writing, compression, and retrieval operators
\citep{zeng2026mementogui}. AndroTMem retrieves causally linked anchor states
from interaction histories \citep{shi2026androtmem}. These systems establish
that long-horizon GUI control benefits from selective memory, but score
candidates largely independently of how much recent visual context is already
present. \method{} makes that conditioning explicit and additionally trains the
policy-side interface that consumes the restored evidence.

\paragraph{Interventional memory value.}
Recent work studies memory through controlled interventions or active state
influence \citep{srivastava2026cmi,liu2026atmem}. Our intervention is narrower
and executable: every event always retains the same low-fidelity record, while
a selected event additionally exposes exactly one archived post-action image,
holding the remaining prompt fixed. The resulting score is a policy-specific
behavioral surrogate rather than an environment-level causal effect.
Coalition-conditioned marginals are related to cooperative-game attribution
\citep{shapley1953value}, but our goal is a deployable budgeted selector for a
fixed GUI policy, not a generic attribution value.

\section{Problem Formulation}

At decision $t$, the agent receives instruction $g$, current observation
$x_t$, and history
\begin{equation}
H_t=\{e_1,\ldots,e_{t-1}\}, \qquad
e_j=(x_j,a_j,x_{j+1}),
\end{equation}
where each event keeps a compact low-fidelity record $\tilde e_j$ and an
archived high-fidelity post-action screenshot $v_j$.

\paragraph{Conditional base context.}
For $r\ge 0$, define the base context
\begin{equation}
\ctx{r} \;=\; g
\;+\;\{\tilde e_1,\ldots,\tilde e_{t-1}\}
\;+\;x_t
\;+\;\mathrm{Recent}\text{-}r,
\label{eq:cr}
\end{equation}
i.e.\ the goal, the \emph{complete} textual action summaries, the current
screenshot, and the $r$ most recent distinct history screenshots. Let
$Q(\cdot)$ denote the policy's mean target-token log-likelihood of the
successful next action under a context. One additional visual slot admits
three actions:
\begin{align}
\Delta_{\mathrm{STOP}}(r) &= 0,\\
\drecent(r) &= Q(\ctx{r}+\{\text{next recent}\})-Q(\ctx{r}),\\
\dsparse(j\mid \ctx{r}) &= Q(\ctx{r}+\{v_j\})-Q(\ctx{r}).
\end{align}
The selector's target decision is
\begin{equation}
\arg\max\bigl\{0,\; \drecent(r),\;
\dsparse(j_1\mid \ctx{r}),\ldots\bigr\},
\label{eq:decision}
\end{equation}
and the paper's central quantity is the \emph{restoration advantage}
\begin{equation}
\grestore(r)
=\max_j \dsparse(j\mid \ctx{r})-\drecent(r).
\label{eq:grestore}
\end{equation}
It answers: with $r$ recent screenshots already present, should the last
high-fidelity slot hold more contiguous history or one task-relevant non-local
event? Within each $r$, all compared prompts contain the same number of
images, the same summaries, and the same structure; only the provenance of the
added image differs. Across different $r$ the total image count differs, so
cross-$r$ absolute scores are analysis, not the causal comparison.

\paragraph{Budgets beyond one slot.}
For at-most-$B$ selection the same construction extends to sets
$S\subseteq\{1,\ldots,t-1\}$ restored on top of $\ctx{r}$, with
$U_t(S\mid\ctx{r})=Q(\ctx{r}+S)-Q(\ctx{r})$ and conditional marginals
$\Delta_t(j\mid S)=U_t(S\cup\{j\})-U_t(S)$. Every formally reported set
utility reruns the complete selected set; we never report a sum of singleton
gains as the utility of a coalition.

\section{CausalCache}

\subsection{Policy-Preserving History-Gated KV Adapter}

Let $h_l$ be the input to layer $l$'s attention projections. In the last eight
language-model layers, \method{} adds rank-8, $\alpha{=}16$ low-rank residuals
\citep{hu2022lora} only to key and value projections:
\begin{equation}
\begin{aligned}
K_l &= W^K_l h_l + M_{\mathrm{hist}}\,\Delta W^K_l h_l,\\
V_l &= W^V_l h_l + M_{\mathrm{hist}}\,\Delta W^V_l h_l.
\end{aligned}
\end{equation}
$M_{\mathrm{hist}}$ is a token mask that is true only for restored historical
image tokens. It excludes instruction tokens, event-summary text, the current
observation image, and action tokens. The mask is constructed fail-closed from
the multimodal token-type sequence and per-image patch geometry; any mismatch
between declared images and encoded image blocks aborts the forward pass.
When no history image is restored, the adapter context is absent and the
projection hook returns the original module output, so
$\adapted(\cdot\mid \ctx{0})=\base(\cdot\mid \ctx{0})$ up to bitwise equality
in our implementation.

\subsection{Per-$r$ Difference-in-Differences Supervision}

Training states are decision points of successful desktop trajectories in
which the target action $a^*_t$ recurs earlier in the same trajectory under
full-action equivalence (type, arguments, and coordinates within tolerance);
the screenshot preceding the earlier occurrence is the target-specific
positive frame. For each state and each conditioning level $r$ we construct
four prompts with identical summaries, current screen, and target:
\begin{itemize}
    \item \textbf{Base}: $\ctx{r}$ alone;
    \item \textbf{Recent}: $\ctx{r}+\{\text{next recent frame}\}$;
    \item \textbf{Sparse}: $\ctx{r}+\{v_{j^{+}}\}$ with the target-specific
    archived frame ($\mathrm{age}\geq 3$);
    \item \textbf{Wrong}: $\ctx{r}+\{v_{j^{-}}\}$ with an age-matched
    same-trajectory frame whose following action is \emph{not} equivalent to
    $a^*_t$.
\end{itemize}
Positives do not require the base action to be wrong: both information
addition and evidence amplification are admissible mechanisms.

Let $\ell$ denote mean target log-likelihood, superscripted by adapter state
(active or frozen bypass). Each arm is anchored to \emph{its own} frozen
score:
\begin{equation}
\begin{aligned}
A_s&=\ell^{\mathrm{on}}_{\mathrm{sparse}}-\ell^{\mathrm{off}}_{\mathrm{sparse}},\qquad
A_r=\ell^{\mathrm{on}}_{\mathrm{recent}}-\ell^{\mathrm{off}}_{\mathrm{recent}},\\
A_n&=\ell^{\mathrm{on}}_{\mathrm{wrong}}-\ell^{\mathrm{off}}_{\mathrm{wrong}},
\end{aligned}
\end{equation}
and the DiD objective is
\begin{equation}
\begin{aligned}
\mathcal L ={}& [m-(A_s-A_r)]_+ + [m-A_s]_+ \\
&+ [m-(A_s-A_n)]_+ \\
&+ \lambda_{\mathrm{cap}}\bigl([|A_r|-\epsilon]_+ + [|A_n|-\epsilon]_+\bigr)
+ \lambda\lVert\Delta W\rVert_2^2,
\end{aligned}
\label{eq:did}
\end{equation}
with $m{=}0.01$, $\epsilon{=}0.02$, $\lambda_{\mathrm{cap}}{=}2$,
$\lambda{=}10^{-4}$, and no action cross-entropy. On the identity adapter
every increment is zero, so $A_s-A_r$ is exactly zero: the frozen policy's
own preference for target-relevant frames cannot masquerade as adapter skill,
and uniformly amplifying all history buys nothing. The dead-zone caps bound
recent-only and wrong-history drift with gradients on the same scale as the
selection hinges. Losses and evaluation are stratified by $r$; a pooled mean
could hide a method that helps at $r{=}4$ but fails at $r{=}0$ or saturates
at $r{=}8$.

\subsection{Success-Anchored Utility and Selector Supervision}

After the history interface is frozen, selector labels are true policy
utilities: for each state and sampled $r$, singleton utilities
$\dsparse(j\mid\ctx{r})$ for the full candidate pool, the matched
$\drecent(r)$, and---for budgets beyond one---set utilities along
shortlisted, recent, greedy, and small-beam paths. All labels rerun complete
prompts through the frozen \hgkv{} policy.

\subsection{$r$-Aware Budgeted Selector}

The selector should use the same interface through which the policy reads
history. For each candidate and each adapted layer we capture a lightweight
counterfactual readout: the frozen decision query attends to the candidate's
history keys/values with and without the adapter increments, and the
mean-head difference plus per-head norms give 160 features per layer (1{,}280
per candidate). The input additionally encodes, explicitly, the number of
recent images $r$ already present, candidate age and action family, summary
features, and the remaining budget.

A shared encoder with learned attention over the eight adapted layers feeds
four heads: predicted marginal $\widehat{\dsparse}(j\mid\ctx{r})$, within-state
rank, positive probability, and STOP. Set-conditioned selection for
$B{>}1$ contextualizes selected-event embeddings with one self-attention block
and maps remaining candidates to that context with one cross-attention block
\citep{zaheer2017deepsets,lee2019settransformer}. At each step the best
remaining candidate rank is compared against next-recent and STOP, realizing
Eq.~\ref{eq:decision}. Training states sample
$r\in\{0,1,2,4,8\}$ with a deployment-tilted mixture
($10/15/20/35/20\%$, subject to label yield), so a single selector serves all
conditioning levels.

\section{Experimental Setup}

\subsection{Training Data and Model Selection}

Policy adaptation and selector training use only desktop data: successful
AgentNet/OpenCUA Ubuntu trajectories (5{,}000 screened, 2{,}293 successful,
6{,}003 decision points) yield 969 target-recurrence groups
(train/dev/test $=773/94/102$, trajectory-disjoint; click $56\%$, key
$35\%$, plus type/drag/scroll), complemented by a high-precision OSWorld
witness seed mined from official successful trajectories. Checkpoints and
thresholds are selected only on the desktop development split under
pre-registered gates: positive DiD selection with a positive bootstrap lower
bound, and drift caps $|A_r|,|A_n|<\epsilon$. No mobile benchmark data
touches training or selection.

\subsection{Policies and Memory Baselines}

The frozen policy is GUI-Owl-1.5-8B-Instruct \citep{xu2026mobileagent35}. We
compare four policy rows under identical data, steps, and cadence:
\begin{itemize}
    \item \textbf{Frozen}: no trainable adapter;
    \item \textbf{Full-layer LoRA}: all language-model Q/K/V/O projections
    \citep{hu2022lora}, always active;
    \item \textbf{Ungated KV}: the same last-eight layers, K/V targets, rank,
    and alpha as \hgkv{} but active on all tokens;
    \item \textbf{\hgkv{} (ours)}: token-gated, structurally bypassed at
    $B{=}0$.
\end{itemize}
Memory baselines are STOP, Recent (the next contiguous frame), Random,
OCR/RGB similarity, and the learned $r$-aware selector; an oracle over the
candidate pool bounds headroom. Every method receives the same summaries and
the same image budget.

\section{Results}

\subsection{Selectivity Is Not Inherited from the Frozen Policy}

On the desktop development split (94 groups, 77 trajectories, $r{=}0$), the
choice of recent control matters. Against a \emph{redundant} control that
restores a byte-identical copy of the current screen (the deployment
recent-selector's $k{=}1$ behavior), the frozen policy prefers the
target-relevant archived frame by $+0.0333$ nats/token
($95\%$ CI $[+0.0118,+0.0567]$). Against the \emph{informative} true previous
frame, however, its preference vanishes: $+0.0013$
$[-0.0242,+0.0253]$, not significant (94/94 probes have a previous frame that
differs from the current screen). To the frozen policy, a task-relevant
non-local frame and the most recent distinct frame are worth about the same;

\section{Ablations and Analyses}

Planned ablations follow the conditional factorization. Policy-side: per-$r$
stratified DiD gates for \hgkv, ungated KV, and full-layer LoRA (a pooled mean
may hide help at $r{=}4$ and saturation at $r{=}8$); adapter depth and rank;
removing the gain, content, or cap terms. Selector-side: with and without the
explicit $r$ input; label-mixture sensitivity; candidate-pool size; STOP
calibration; top-$B$ versus bottom-$B$ restoration; wrong-event and
summary--image mismatch controls. We also stratify by trajectory length,
application, and positive-frame age.

\section{Limitations and Claim Boundary}

Our frozen claim is deliberately conditional:
\begin{quote}
Given textual summaries, the current screen, and a variable amount of recent
visual context, \method{} estimates the conditional marginal utility of
restoring each archived event at high fidelity. Under a matched one-image
budget, it restores a non-local screenshot only when doing so is more useful
than extending the contiguous recent window.
\end{quote}
The claim is \emph{not} that sparse history beats recency in general; it is
that in identifiable states the conditional marginal of a key archived event
exceeds the next recent frame, and \method{} learns to recognize those states
and events. The teacher-forced likelihood surrogate must ultimately be judged
by closed-loop success. ``Causal'' refers only to controlled restoration
interventions holding the remaining prompt fixed, not environment-level
structural causality. The desktop DiD evidence reported here instantiates the
$r{=}0$ row; its training-time recent arm followed the deployment selector,
whose $k{=}1$ frame duplicates the current screen, so we separately re-scored
the selected checkpoint against the true previous frame and report both
controls. The $r$-conditioned corpus (v2) freezes ``next recent'' as the most

\section{Conclusion}

\method{} reframes visual memory for GUI agents as a conditional decision:
given what recent context is already present, spend the next high-fidelity
slot on recency, on one archived non-local event, or not at all. A token-gated
KV interface learns to use restored evidence inside a pre-registered drift
envelope---where full-layer adaptation cannot stay---and an $r$-aware selector
learns when restoration beats recency. All learning happens on desktop data;
mobile benchmarks remain untouched for zero-shot evaluation.
