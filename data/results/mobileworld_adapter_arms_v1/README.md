# 适配器三臂闭环(同批 Recent-4):frozen / 门控 / 无门控

## 这一轮回答什么

1. 无门控全层 LoRA 在离线上选择性翻倍、中性门全破,**闭环上到底是赚是亏**?
2. HGKV 的"部署行为中性"claim,在**同批同轮**条件下还成立吗?

第 2 问是被一个伪信号逼出来的:中期用 n=64 子集看到门控臂 35.3%,远高于论文里
冻结基线的 29.9%,一度怀疑"过了离线中性门 ≠ 闭环中性"。但那两个数来自不同批次
与不同轮数(论文是三轮均值),不可比,于是补了这条同批 frozen 对照。

## 设置

- 117 任务全量,`memory_arm = recent_b4`(**不带 selector**),三臂只差策略侧适配器;
- 门控臂 = `gated36-long` step900(离线 did_select 峰值,全部过门);
- 无门控臂 = `full-lora` step200(离线 did_select 峰值 +0.0291,中性门全破);
- frozen 臂与两个适配器臂同期跑在同一批模拟器上,单轮。

## 结果

| 臂 | 全量 (117) | memory-critical (62) | control (55) |
|---|---|---|---|
| frozen | **33.3%** | 25.8% | 41.8% |
| 门控 last-36 | 31.6% | 29.0% | 34.5% |
| 无门控全层 | 30.8% | 27.4% | 34.5% |

配对 bootstrap(4000 次,任务级):

| 对比 | 全量 | memory-critical |
|---|---|---|
| 门控 − frozen | −1.7pp [−7.7,+4.3] | +3.2pp [−4.8,+12.9] |
| 无门控 − frozen | −2.6pp [−9.4,+4.3] | +1.6pp [−8.1,+11.3] |
| 门控 − 无门控 | +0.9pp [−2.6,+4.3] | +1.6pp [−3.2,+8.1] |

**三臂统计上不可区分**,全部区间跨零。117 个任务里门控与无门控只有 5 个结果不同。

## 三条结论

1. **HGKV 部署中性得到同批验证**:门控 31.6% vs frozen 33.3%,差异在噪声内。中期
   那个"35.3% 说明不中性"的怀疑是子集偏差造成的伪信号,已推翻。
2. **离线指标不预测闭环**:无门控臂离线选择性是门控的两倍(+0.0291 vs +0.0145)、
   wrong 漂移是六倍(0.031 vs 0.005),闭环上却与门控、与 frozen 三方无异。既不预测
   收益,也不预测行为改变。
3. **适配器本身不带来闭环收益**:固定 Recent-4 分配下三臂一样,说明论文主结果的
   +6.6pp 来自 **selector 的重新分配**,而不是策略侧适配。这与"探针只在训练时有用、
   部署时可弃"的主张一致。

## 2×2 全表(已补齐,117 任务全量)

| 策略侧 | Recent-4 | + selector | selector 增益 |
|---|---|---|---|
| frozen | 33.3 / 25.8 | 36.8 / 30.6(论文三轮均值,未在本批复跑) | — |
| 门控 last-36 | 31.6 / 29.0 | **35.9 / 30.6** | +4.3pp [−1.7,+10.3] |
| 无门控全层 | 30.8 / 27.4 | **35.0 / 29.0** | +4.3pp [−2.6,+11.1] |

(斜杠后为 memory-critical;明细见 `adapter_2x2_paired.json`)

1. **selector 稳定带来 +4.3pp,且在两种适配器上数值完全相同**——增益来自记忆
   重分配,与策略侧挂什么无关。
2. **门控 vs 无门控在 selector 下同样无差别**(+0.9pp,CI [−4.3,+6.0]),与
   Recent-4 下的结论一致。
3. **挂适配器都不如不挂**:最好的适配器组合 35.9%,仍不及 frozen + selector 的
   36.8%。"探针训练时有用、部署时可弃"在 2×2 的两个维度上都得到支持。

注:frozen + selector 未在本批复跑(用论文三轮均值),与其余四格严格同批的比较
待补;但四格之间互为同批,上述三条结论不依赖那一格。
