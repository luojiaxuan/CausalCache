# 门控全层(last_36)对照:隔离"门控"这一个因素

## 为什么要这一轮

`../desktop_did_v5_fulllora`(无门控全层)两条中性门未过,一度被解读为"全层适配
必然破坏行为中性,所以 HGKV 的门控设计是必要的"。这个归因当时**不成立**:

- 现成的 HGKV 报告(`../desktop_did_v5_selected/`,last_8 与 last_36)训练语料只有
  **1078 个训练单元**,反复看 2.2 遍;无门控那轮是 **12452 个单元**各看一遍;
- 于是"层范围"、"有无门控"、"数据多样性"三个因素纠缠在一起。

本轮把语料与预算完全对齐,只留下"有无门控"一个差异。

## 配置差异(与 `../desktop_did_v5_fulllora` 逐项对照)

| | 本轮 gated36-matched | fulllora |
|---|---|---|
| adapter | `history_gated_kv`, last_36 | `full_policy_lora`, 全层 |
| target modules | k/v | q/k/v |
| 语料 | v5-selected 修复版,12452 单元 | 同左 |
| 预算 | 300 steps × accum 2 × 4 ranks | 同左 |
| lr / rank / alpha | 1e-4 / 8 / 16 | 同左 |

## 结果

v4b1 口径:

| ckpt | did_select | recent_abs | wrong_abs | 门控 |
|---|---|---|---|---|
| step100 | +0.0062 [+0.002,+0.011] | 0.0133 | 0.0032 | ✓ |
| step200 | +0.0121 [+0.006,+0.018] | 0.0141 | 0.0051 | ✓ |
| step300 | +0.0145 [+0.009,+0.021] | 0.0135 | 0.0086 | ✓ |

v5hit 口径同向(step300:did_select +0.0130、recent 0.0137、wrong 0.0097,
step150 起全过)。

## 并排结论(同语料同预算,只差门控)

| | did_select 峰值 | recent 漂移 | wrong 漂移 | 门控 |
|---|---|---|---|---|
| 门控 last-36 | +0.0145 | 0.011–0.014 | 0.003–0.010 | **全过** |
| 无门控全层 | +0.0291 | 0.018–0.027 | 0.003–0.031 | **全不过** |

1. **门控是漂移控制器**:wrong 漂移 6 倍差(0.005 vs 0.031),recent 漂移
   0.013 vs 0.025。门控版稳在 ε=0.02 包络内,无门控版从第一个检查点就顶破。
2. **代价是选择性减半**(+0.0145 vs +0.0291)。无门控全层确实学得更强,它只是
   不再是干净的测量仪器——测出的效用混入了泛化性行为改变。
3. **小语料的旧数字偏乐观**:同为门控 last_36,小语料版(1078 单元、2.2 epoch)
   did_select 报 +0.0249,大语料版只有 +0.0145。小语料与 dev 集可能共享 episode,
   有过拟合嫌疑。**论文若引用门控 last_36 的离线数字,应以本轮大语料版为准。**

## 对"能不能改用全层 LoRA 替代 HGKV"的回答

可以,但要换故事:全层无门控 LoRA 作为**部署策略**是合理选项(行为改变本就是
目的),但那时它不再是 frozen policy,闭环对比会把"记忆分配收益"与"策略变强"
混在一起,必须补一条 `adapted policy + Recent-4` 基线才能拆开。作为**测量仪器**
则不合格,因为它破坏了预注册的中性包络。
