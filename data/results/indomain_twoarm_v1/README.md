# 同批双臂:修复后的 selector vs Recent-4(同域,OSWorld 15 步)

> **两轮定论(2026-08-02):第 1 轮的 +2.22pp 没有复现。两轮平均 +0.83pp,
> CI [−1.25, +3.05],p=0.24——修复未能在同域产生可判定的闭环收益。**
> 详见文末「两轮结果」。以下第 1 轮小节保留原样,作为"单轮会骗人"的实例。

## 第 1 轮结果

同一时间窗、同一批机器、各 361 任务全量。

| 臂 | 成功率 |
|---|---|
| **selfix**(全量语料重训 + 部署口径选 checkpoint + 校准截距 +0.0661 + τ=0 弃权) | **32.69%** |
| **recent**(同批 Recent-4 对照) | **30.47%** |
| **同批配对差** | **+2.22pp**,CI95 [−0.83, +5.54],p(Δ≤0)=0.10 |
| 不一致 | 赢 22 : 输 14,翻转 10.0% |

**判定:方向为正、幅度翻倍、目标故障消失,但未达显著。不能声称同域已解决。**

## 与历史臂的对比(注意口径)

| | 点估计 | 赢:输 |
|---|---|---|
| 历史 LA vs 历史 recent(跨轮) | +1.11pp | 25:21(1.19) |
| **selfix vs 同批 recent** | **+2.22pp** | **22:14(1.57)** |

**同批对照的必要性有了直接证据**:同一个 Recent-4 臂,历史轮 32.96%、本轮 30.47%,
**跨轮差 2.5pp**。此前所有同域比较都是跨轮的,因此都不可靠——包括那个 +1.11pp。

(`twoarm.json` 里也记了 selfix 对**历史** recent 的跨轮差 −0.28pp。这个数**不要引用**,
它正好演示了跨轮比较如何把 +2.22 变成 −0.28。)

## 弃权真的起作用了(与上一轮空转对比)

| | τ=0 无截距 | **τ=0 + 截距** |
|---|---|---|
| promoted = 0(完全弃权) | 97.4% | **0%** |
| promoted = 1 | 1.4% | **69.8%** |
| promoted = 2 | 0.03% | **29.8%** |
| 真正偏离 recent 的步 | ~2% | **25.7%** |

校准截距把选择器从"永远弃权"变成"每步提升 1-2 张、其中 25.7% 真正偏离 recent"。
**这证实了修复顺序的判断:先校准,弃权才有意义。**

## 域级:目标故障确实被修掉了

| 域 | 历史 LA(赢:输) | **selfix(赢:输)** | 变化 |
|---|---|---|---|
| **libreoffice_writer** | **0:4(净 −4)** | **3:2(净 +1)** | **修复** |
| libreoffice_impress | 2:4(−2) | 2:2(0) | 改善 |
| thunderbird | 0:2(−2) | 1:2(−1) | 改善 |
| libreoffice_calc | 4:2(+2) | 5:1(**+4**) | 增强 |
| os | 3:1(+2) | 4:1(**+3**) | 增强 |
| vs_code | 2:2(0) | 3:1(**+2**) | 增强 |
| multi_apps | 4:2(+2) | 1:2(**−1**) | **退化** |
| gimp | 4:1(+3) | 1:1(0) | 退化 |

**弃权机制的设计目标——消除单应用文档类的损害——达成了**(writer −4 → +1,
impress、thunderbird 均改善)。

但 multi_apps(+2 → −1)与 gimp(+3 → 0)退化了,这两个恰是跨应用/图形类,
即**最该受益**的域。可能的解释:τ=0 过于保守,把这些域里本该提升的远端帧也弃权掉了。
每域样本量 15–93,单个任务翻转即 1–7pp,**不要过度解读单域数字**。

## 统计力:需要多少轮

| | |
|---|---|
| 配对标准误 | 1.66pp |
| 95% 半宽 | 3.26pp |
| 观测效应 | +2.22pp |
| **达到显著所需** | **约 2.2 轮全量** |

按今晚测出的噪声地板(近乎相同的两臂翻转 14.4%),单轮 361 任务分辨不了 4pp 以内的
效应。**要把 +2.22pp 坐实,最少需要再跑 2 轮**(约 2.5 小时机时),或改用步级/效用级指标。

## 结论与建议

1. **不要在论文里声称"同域已修复"。** 现有证据支持的说法是:
   "修正部署侧校准缺陷并引入弃权后,同域点估计从 +1.1 提升到 +2.2pp,
   且此前集中在单应用文档类的系统性损害消失;但单轮口径下仍不显著。"
2. **下一步优先级**:补 2 轮同批双臂把这个效应做实,成本约 2.5 小时,
   比做修复 3(特征增强)更值。
3. **τ 值得调**:当前 τ=0 是模型自身边界、无调参。域级证据提示它对
   multi_apps/gimp 偏保守。可在 dev 上按 replay_gain 选 τ,或按域自适应。

# 两轮结果(定论)

第 2 轮与第 1 轮**完全同配置、同批对照、同机同分片**,唯一差别是时间窗。

| 轮 | selfix | recent(同批) | 配对差 | 不一致 |
|---|---|---|---|---|
| 第 1 轮 | 32.69% | 30.47% | **+2.22pp** [−0.83, +5.54] | 22:14 |
| 第 2 轮 | 29.36% | 29.92% | **−0.55pp** [−3.60, +2.49] | 15:17 |
| **两轮平均** | **31.02%** | **30.19%** | **+0.83pp** [−1.25, +3.05] | — |

两轮平均 p(Δ≤0) = **0.244**。

## 结论

**修复未能在同域产生可判定的闭环收益。** 第 1 轮的 +2.22pp 是单轮波动,没有复现。

这不是"修复无效"的证明,而是"**在这个口径下测不出**"的又一次确认:

- selfix 臂两轮自身波动 **32.69% → 29.36%(3.33pp)**;
- recent 臂两轮自身波动 **30.47% → 29.92%(0.55pp)**;
- 两臂的轮间波动量级与待测效应相当,这正是先前测出的 14.4% 噪声地板的表现。

**不要把 +0.83pp 写成"小幅正向"。** 诚实的表述是:两轮 n=722 仍不足以判定,
真实效应若存在也小于约 3pp。

## 这两轮验证了什么(仍然有价值)

1. **同批对照是必需的**:同一 recent 臂在三个不同时间窗分别是 32.96% / 30.47% / 29.92%,
   跨轮差最大 3.0pp——**任何跨轮比较都不可信**。
2. **校准修复确实改变了行为**:弃权从 97.4% 全弃权变为每步提升 1-2 张、25.7% 真正偏离
   recent(见上文审计表)。行为改变是确凿的,只是没有转化为成功率。
3. **第 1 轮的域级"修复"信号也不可信**:writer 0:4 → 3:2 看着像修好了,但既然总体效应
   没复现,单域 n=23 的翻转更不能作为证据。**这是"看到想看的模式"的典型陷阱**,
   我在第 1 轮报告时应当更保守。

## 对下一步的含义

任务成功率在这个基准的单轮/双轮口径下**没有分辨 3pp 以内效应的能力**。要继续推进同域,
只有三条路:

1. **换指标**:用步级/效用级度量(如 replay_gain、top1-regret)做主判据,
   任务成功率只作辅助。离线口径下修复 1 的收益是确凿的(+0.0023 → +0.0066)。
2. **加轮数**:按当前效应量,判定 ±1pp 需要约 10 轮全量(约 12 小时机时),性价比低。
3. **换工作点**:oracle 头寸在 B=2 是 +0.102、B=4 只剩 +0.037。**B=4 本就是最难
   展示价值的点**;若改在 B=2 上做同域对照,效应量应显著更大。
