# 门控全层 900 步加长版:训练量对漂移与选择性的作用

## 动机

300 步版(`../desktop_did_v5_gated36_matched`)结束时 did_select 仍在上行而漂移
已走平,于是用空闲卡把同配置训到 900 步(≈0.6 epoch),检验"延长训练能否白赚
选择性"。检查点每 150 步。

## 结果

| ckpt | did_select (v4b1) | did_select (v5hit) | recent_abs | wrong_abs | 门控 |
|---|---|---|---|---|---|
| 150 | +0.0113 | +0.0104 | 0.0125 | 0.0065 | ✓ |
| 300 | +0.0133 | +0.0141 | 0.0135 | 0.0077 | ✓ |
| 450 | +0.0151 | +0.0168 | 0.0158 | 0.0006 | ✓ |
| 600 | +0.0132 | +0.0153 | 0.0155 | 0.0047 | ✓ |
| 750 | +0.0160 | +0.0172 | 0.0123 | 0.0053 | ✓ |
| 900 | +0.0193 | +0.0171 | 0.0143 | 0.0102 | ✓ |

(recent_abs / wrong_abs 列为 v4b1;v5hit 同量级:0.0125–0.0169 / 0.0004–0.0086。)

## 两个结论

1. **门控把漂移钉住,与训练量无关。** 训练量翻三倍(300→900),recent 漂移仍是
   0.012–0.016,没有任何上行趋势;对照之下无门控全层随训练从 0.018 爬到 0.027。
   这比"门控降低漂移"更强——它让漂移不随训练增长。
2. **选择性在 step≈450 后饱和,不是持续上行。** v4b1 看似涨到 +0.0193,但 v5hit
   自 450 起就在 +0.017 横盘;step900 与 step450 的置信区间大幅重叠。两套平均:
   450→900 算力翻倍只换 +0.002。据此**放弃了 900→1800 的续训**(已启动后终止),
   预期收益约 +0.002,不足以逼近无门控的 +0.029。

## 三方并排(同语料 v5-selected 修复版)

| 配置 | did_select 峰值 | recent 漂移 | wrong 漂移 | 门控 |
|---|---|---|---|---|
| 门控 last-36,300 步 | +0.0145 | 0.011–0.014 | 0.003–0.010 | 全过 |
| 门控 last-36,900 步 | +0.0193 (v4b1) / +0.0171 (v5hit) | 0.012–0.017 | 0.000–0.010 | 全过 |
| 无门控全层,300 步 | +0.0291 | 0.018–0.027 | 0.003–0.031 | 全破 |

无门控全层的选择性优势**不是"训得快"能被追平的**:门控版训到 3 倍算力仍停在
+0.017–0.019。所以两者是真实的权衡——门控买中性,代价是选择性上限更低。
