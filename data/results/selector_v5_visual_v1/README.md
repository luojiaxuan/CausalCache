# 方案 3(免 pass-2 的视觉 selector):**均值池化的帧 embedding 不携带该信号**

> **结论:不是架构不够,是表示不对。** 候选帧与当前帧的 embedding 相似度在
> 5,335 个状态上与**随机打乱不可分辨**(组内 Spearman −0.0014,CI95
> [−0.0122, +0.0093];random 为 −0.0045,CI 几乎完全重叠),而纯 recency 有
> 明确非零的 +0.0634。据此,在这套 1152 维均值池化表示上做任何交互块都是徒劳,
> **应当停止在此方向投入算力**,改换表示(patch 级 / 与指令交叉)后再谈。

## 为什么先测这个

方案 3 的第一版训练结果里,三臂几乎逐位相同:

| 臂 | witness 来源 | 视觉 | dev_top1_regret | dev_spearman | replay_gain_b2 | 早停 |
|---|---|---|---|---|---|---|
| `la_cheap` | last_action(单遍) | 无 | 0.0986 | **0.1516** | −0.0105 | ep40,best ep25 |
| `la_visual` | last_action(单遍) | **有** | **0.0977** | 0.1498 | −0.0104 | ep20,best **ep5** |
| `p_cheap` | 真值目标(需 pass-2) | 无 | 0.1028 | 0.1443 | **−0.0154** | ep40,best ep25 |

视觉臂在 Spearman 上甚至**略低**;三臂全距 0.005,远小于任何可解释的尺度。

**两个反直觉之处,都指向同一件事:**

1. `p_cheap` 用的是**真值目标**算 witness(比部署时的 proposal 还强,是理论上界),
   却在三个指标上**全部最差**。也就是说在这套冻结教师语料上,witness 家族
   不但不是"pass-2 买来的关键信息",反而略微有害。
2. **三臂的 `replay_gain` 全为负**——都不如 Recent 锚。`model_set_size_dist`
   显示模型绝大多数状态停在 size 1(预测边际 ≤0 就弃权),
   所以 replay 指标主要反映的是弃权校准,不是排序质量。

关键是**两臂都欠拟合**:`train_probe_top1_regret` 0.0878 vs dev 0.0977,
训练损失 40 轮只从 0.806 降到 0.795。**欠拟合 + 加特征无变化**,通常指向
"特征里没有可学的东西",而不是"模型不够大"。所以先用无需训练的判据判死,
而不是去调超参——调参要烧几小时,这个判据几分钟。

视觉特征确实接上了,不是接线问题:日志里
`{"visual_dim": 1152, "visual_frames": 27406, "cand_coverage": 1.0, "cur_coverage": 1.0}`。

## 判据(`code/scripts/probe_frame_embedding_signal.py`,纯 CPU)

对每个决策点,把候选帧的真值边际 $\Delta U(j) = U(\{j\}) - U(\emptyset)$
(单例表)与几个**零训练**的相似度打分做**组内** Spearman。组内而非全局,
是因为不同状态的 $\Delta U$ 尺度差异会淹没组内排序。

| 打分器 | 组内 Spearman | CI95 | top-1 命中 oracle |
|---|---|---|---|
| `cos_cq` $\cos(e_j, e_{now})$ | **−0.0014** | [−0.0122, +0.0093] | 13.7% |
| `negdist` $-\lVert e_j - e_{now}\rVert$ | −0.0010 | [−0.0117, +0.0097] | 13.1% |
| `cos_cmean` 与候选均值的 cos | −0.0013 | [−0.0120, +0.0094] | 13.3% |
| **`age`** $-(t - j)$,即 Recent 排序 | **+0.0634** | [+0.0500, +0.0768] | **16.8%** |
| `random` 打乱的真值 | −0.0045 | [−0.0151, +0.0061] | 12.8% |

n = 5,335 个状态(候选 ≥3),当前帧 embedding 缺失 0 个。

三个 embedding 打分器的 CI 都跨零、且与 `random` 的 CI 几乎完全重叠;
`age` 的 CI 不跨零,与它们不重叠。

## 解释

均值池化把 1920×1080 桌面截图的全部 patch 压成一个 1152 维向量。
两张"同一个桌面、只是多开了一个对话框"的截图,均值池化后几乎相同。
而"这张旧图里有我现在要输入的那个文件名"这类信号**存在于极小的局部区域**,
正是被均值池化抹掉的部分。

## 边界(不要过度外推)

- 本判据测的是**零训练的余弦/距离**,不等于"embedding 里绝对没有可学信号"。
  学出来的投影原则上可能提取到裸余弦看不到的东西。
- 但**训练出来的 320k 参数交互块同样没提取到任何东西,且欠拟合**。
  两条独立证据指向同一结论,合起来才是本文的判断依据;单看任一条都不够。
- 顺带一个对整个 selector 问题都重要的事实:**最好的单一便宜信号(recency)
  组内 Spearman 只有 0.063**,训练好的 28 维 selector 也就 0.15。
  即 $\Delta U$ **很难从便宜特征预测**。

  注意这**不等于**"标签有噪声"。语料里 52,823 条单例与 79,151 个集合
  **没有任何重复键**,而 $U$ 是教师强制下目标动作的对数似然、前向确定,
  所以不存在测量噪声,也就不能说 oracle 空间是被噪声抬高的。
  真正待验证的是另一件事:**$U$(离线对数似然)与闭环成功率之间的落差**
  ——这才是"离线门控全过、闭环无提升"的候选解释。

## 下一步(若要继续方案 3)

换表示,不是换架构:

1. **patch 级检索**:保留 patch token,用当前帧的 query patch 去检索候选帧的
   patch(max-sim 而非 mean-mean),即 ColBERT 式后期交互;
2. **与指令交叉**:embedding 里注入任务文本,让"有没有用"以目标为条件;
3. 若两者都不行,方案 3(免 pass-2)在**当前教师标签**下不成立。

   注意第 3 条不能反过来说成"所以 pass-2 是必要的"——本次 `p_cheap`(真值目标
   witness,比 pass-2 的 proposal 更强)恰恰最差。
