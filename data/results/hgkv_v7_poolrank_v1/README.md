## 遗留疑点

门控里 $A_r = -0.00514$(recent 臂被压低),而同底 k=0 是 +0.00139(接近中性)。
两者语料与 prompt 不同、不直接可比,但"是否真的损害了 recent"仍需盯:
若后续证实,定向修法是加单边罚项 $[-A_r]_+$(只禁止打坏 recent、不奖励绝对幅度,
区别于恢复 `L_gain` —— 那会把均匀抬升的激励放回来)。

## 分解:改善来自哪一侧

$$\text{did\_select} = A_c - A_r \;\Rightarrow\; \Delta\text{did\_select} = \Delta A_c - \Delta A_r$$

| 项 | 值 | 正确读法(结合同底 k 分层) |
|---|---|---|
| $\Delta\text{did\_select}$ | **+0.00308** | 改善 |
| $\Delta A_c$ | **−0.00294** | $A_c$ = 均匀 + 选择性;**是均匀那块塌了**,不是选择性变弱 |
| $\Delta A_r$ | **−0.00602** | recent 臂被压低 —— **唯一仍需盯的疑点** |

算术本身没错,但**不能据此推断"适配器整体变弱"** —— $A_c$ 是复合量。
同底 k 分层给出的分解是:均匀 0.0094→0.0014、选择性 0.0028→0.0043。
$A_c$ 下降与选择性上升可以同时成立,而且实际就是这样。

## `L_gain` 与均匀抬升的关系(结论已修正)

v4 config 的 `gain_rationale` 原文:

> 只有 L_select 时,压低 $\ell_{RA}$ 与抬高 $\ell_{SA}$ 同样能减损失,而"把 recent 臂
> 打坏"不是要的能力。L_gain 要求 sparse 臂的绝对增量自己也为正。

这条顾虑是真的 —— 门控里 $A_r$ 确实掉到 −0.005。但它**没有**如担心的那样吃掉
选择性:同底测量显示选择性反而涨了 55%。所以去掉 `L_gain` 的净效果是
**封死了均匀抬升**(它的唯一激励源),代价是失去了"禁止压低 recent"的约束。

**预注册判据的一个缺陷(值得记)**:criterion 1 写的是"$A_c$ 不高于",
而 $A_c$ 是复合量,单看它既可能因为"均匀塌了"下降(好),也可能因为
"选择性没了"下降(坏),**两种情况无法区分**。判据应当直接约束分解出的成分,
而不是约束复合量。这次是靠事后的同底 k 分层才分清的。

## 下一步的定向修法(若 $A_r$ 的下降被复现证实)

保留"全是差"的结构(它确实封死了均匀抬升),另加一个**单边**约束禁止 $A_r$ 下降:

$$\mathcal L_{\text{floor}} = \lambda_{r}\,[-A_r]_+$$

它只惩罚"把 recent 打坏",**不奖励绝对幅度**,所以不会把均匀抬升的激励放回来 ——
与直接恢复 `L_gain`(奖励 $A_c$ 变大 → 均匀抬升重新有利可图)是两回事。
