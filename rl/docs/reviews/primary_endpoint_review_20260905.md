# 外审:主终点该怎么定(GPT-6 Pro,2026-09-05 05:10 PT)

起因:标注脚本在冻结底座上跑通后发现,两个手写固定选择器都不比随机帧对好(43.3 / 43.8 vs 43.6),
于是我担心以 `I(q)` 为主终点会围绕零抖动。带着这个问题发审。

## 1. 审前判断(先写后审)

- 主终点沿用上一轮外审定的 `I(q) = [V_S(q)−V_S(r)] − [V_C(q)−V_C(r)]`;
- 我的担心:q 无效 ⇒ V(q) 是噪声 ⇒ 交互效应测不出真实效应;
- 打算的处置:用训练任务上的标签拟合一个 q,再固定到未见模板评估。

## 2. 外审要点(逐条转录,英文原文见 §5)

**开场判决**:"your original endpoint is too narrow for the broad claim, and your pilot does not
establish that no usable selector exists. It establishes that two heuristics failed."

### 我的前提有逻辑错误

`I(q) = [V_S(q) − V_C(q)] − [V_S(r) − V_C(r)]`。**底座根本不出现在这个式子里**。
一个在底座上零优势的选择器,训练后完全可能获得优势;反过来,训练若同等地改善了"选中历史"与
"最近历史"的利用,`I(q)` 也会是 0 而实际上历史效用真的提升了。所以问题不是 q 弱,而是
**`I(q)` 测的是两种历史策略的差异效用,不是历史本身的效用**。

### 主终点改为「有历史 vs 无历史」

定义 `H_a = V_a(U) − V_a(0)`,U = 15 个候选帧对上的均匀分布,0 = 不给任何历史截图
(其余提示信息完全不变——如果我方的 null 条件同时去掉了文本动作历史,那它不是干净的截图消融)。
主终点改为

    J_{S,C} = H_S − H_C = [V_S(U) − V_S(0)] − [V_C(U) − V_C(0)]

它问的是:**训练方案是否改变了"从指定候选分布里给出历史截图"的平均价值**。
底座上 `H_base = −7.4pp`(历史目前是**有害**的)并不使该终点失效——训练可以减轻这种伤害,
甚至反转它。但**结论措辞必须准确**:把 −7 变成 −2 是"减少了伤害",不是"历史带来了收益"。

### 必须同时报出所有分量均值

差分中的差分可以由**参照条件的恶化**造成。它给的反例:

| checkpoint | V(q) | V(r) |
|---|---|---|
| RECENCY 训 | 45 | 45 |
| RANDOM 训 | 45 | 40 |

此时 `I(q) = +5pp`,而 q 条件下的表现**一点没涨**——这是相对偏好改变,不是检索历史变得更有用。

### 不要把 OLDER 降级

`RANDOM vs RECENCY` 同时改变了"是否看老帧"与"是否散开"两件事。若**散开**才是标题假设,
则关键对比是 `J_{S,O} = H_S − H_O`,应当把它当主对比;否则 S vs C 作总干预对比,而
S vs O 是"散开"这一解释的必要条件。**若 OLDER 与 RANDOM 实际相当而两者都胜 RECENCY,
最简解释是"非最近帧的暴露"起作用,散开未被证明有额外价值**。另:配平了平均帧龄不等于配平了
帧龄分布的全部性质与截图内容,措辞应为"指定取帧方案的效应",不是抽象"布局"的孤立效应。

### (a) q 该怎么学

不要学"视觉上有趣",要学**动作效用**。`Y_sp = 1[在帧对 p 下解码出的动作匹配目标动作]`,
15 个候选的回报**全部可观测**(full-information),因此不需要倾向性得分或重要性加权,
可以直接在回报矩阵上做受限策略学习。做法:正则化的**帧对打分器** `q(s) = argmax_p f(x_s, z_sp)`,
小型线性模型带交互项或浅层提升树;**用留出集上"被选中动作的匹配率"调参,不要用 AUC 或全局预测准确率**
——模型可以很会预测"哪些状态本来就容易"却完全不会在状态内排序。**不要把它变成 15 类里选一个
"最佳帧对"的分类问题**:多个帧对可以同时成功,也可以全部失败。

特征三组:(i) 时序与结构——两帧帧龄、龄差、均龄、轨迹进度、是否含最新帧;
(ii) **任务条件化的内容**——每帧与指令的相似度、与任务实体在界面文本上的重叠、帧对是否覆盖不同的
任务相关内容;(iii) 状态变化与冗余——当前对过去、过去对过去的嵌入距离、屏幕跳转、冗余、
其间的导航/搜索/编辑/选择动作。**我那个失败的"视觉变化最大"启发式缺的正是任务条件化:
屏幕变化大不等于变化有用。** 所有输入必须在解码被选上下文**之前**就存在,排除目标动作。

### (c) 底座的负结果可报,但措辞要改

"No usable selector exists" 不是我现在拥有的结果。可辩护的写法是:

> 在 1,052 个未见状态上,两个受测启发式选择器的动作匹配率为 43.3% 与 43.8%,而 recency 为 43.6%、
> 不给历史为 51.0%。在点估计层面二者均未实质超过 recency。虽然事后在 15 个帧对上择优可达 59.6%,
> 受测选择器没有兑现这一优势。

要更强的主张,需要声明一个低成本的**学习型**选择器族、跨模板评估与不确定度。

### 事后 oracle 的解释与校准

best-of-15 是"在已记录输出中择优"的合法**描述性上界**,但它**用答案去选上下文**,其优势可能来自
有用信息、上下文诱发的预测多样性,或(随机解码下的)采样波动,三者无法区分。
要用无关上下文去校准 oracle,**扰动次数必须可比**——一个无关上下文校准不了 best-of-15。

### (d) 什么会让它不信

- 交互为正但完全来自 recency / 无历史条件变差,而目标历史策略下并未改善 → 那是特化或损伤,不是能力增益;
- 用无关、重复或无信息历史也能得到同等改善 → 更强的解释是"对噪声图像更鲁棒",不是"用上了历史内容";
- OLDER 与 RANDOM 实际等价而两者都胜 RECENCY → 散开不是关键成分;
- oracle 覆盖率上升但平均帧对表现与诚实选择器持平或变差、且可比的诱饵扰动能产生类似的 oracle 增益
  → oracle 上升不构成可用检索的证据;
- 选择增益在未被触碰的模板上消失。

**修订后的预注册判据(三条同时满足)**:
1. `J_{S,C} = H_S − H_C` 在未见模板上显著为正;
2. 分量均值显示 `V_S(U)` 本身不低于 `V_C(U)`(排除"只是参照条件变差");
3. 无关历史条件下 RANDOM 臂的改善**不**与真实历史下的改善同幅(排除"只是对噪声图更鲁棒")。
   若 `H_S ≈ H_O`,则结论收敛为"非最近帧暴露起作用",不主张散开。
