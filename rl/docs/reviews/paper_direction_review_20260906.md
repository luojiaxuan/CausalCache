# 外审:论文方向——构造记忆关键任务(A)还是效率 pivot(B)(GPT-6 Pro,2026-09-06 10:00 PT)

用户提出两条路:A = 让 MobileWorld 出现真正需要记忆图的任务;B = 把固定 B 改成动态 B,做效率(更少视觉 token,同上下文更好效果)。
**注意**:发审时的 GUI-Owl 前提("裁判帧≈无关帧、recency 差于不给图")后被查明是标注布局伪影(台账 10:20 PT 条目);
外审关于 GUI-Owl 的措辞据此打折,但其方法论建议不依赖这一前提。

## 1. 审前判断(先写后审)

合成一条:记忆余量的协议依赖性(第一章)+ 动态 B 控制器,在自然任务上省 token 不掉点、在记忆关键任务上找回 recency 丢掉的余量;
A 的任务集只作载体;决定性实验 = B-pilot 的 checkpoint 表(部署协议下 证据帧 vs recency vs 无关帧)。

## 2. 外审要点(转录)

**判决**:A 是更强的科学方向;**B 现在还不是效率结果**——它只是"一个平凡基线(总是 B=0)可能压过你要造的机器"这一观察。
合起来是最强的论文,但**只能在 A 先证明"保留部署文本策略时,视觉检索仍有用"之后**。原命题(固定 B、非连续帧胜 recency)
目前只是条件假设:有 Venus 去文本后选帧有用的证据,**没有**"原生部署下选非连续帧改善 agent"的证据。
**不要为一个尚未证明在目标设定下存在的收益去造控制器。**

**当前结果究竟确立了什么**:
- "none" 在保留文本时不是"无记忆",是"仅文本历史"——全文改名 **text-only history**。Venus 技术报告明确说推理时保留完整推理历史,
  去掉它是对其报告配置的实质偏离,不是拿掉一个可选附件。可辩护的表述:"在采样状态上,历史截图相对保留的文本轨迹几乎没有增量
  价值;但去掉文本通道后,被选中的截图给 Venus 提供了实质有用的信息。"——有趣,但不等于"视觉检索改善部署中的 GUI agent"。
  且删掉轨迹同时删掉了任务进度、动作解释和已提取事实,图可能只是在**重建 agent 在工作流中的位置**,而非取回某个遗忘的值;
  当前阳性结果没有分离这两种机制。
- 匹配无关帧对照有价值,但**裁判不是 oracle**:三个架构不同的裁判仍是三个不完美的选择器;它们没能改善 Owl 不等于不存在有用的帧对。
  需要**环境溯源的阳性对照:真正含决策相关证据的源帧**。SFT 结果只支持"对历史图干预行为不敏感",不支持"忽略图"的全局主张,
  更不表明记忆利用提升;**在 oracle 帧测试找出消费者侧的可提升能力之前,停止布局 SFT 投入**。
- "不显著"≠等价;54 格、9 格共用状态不是独立复现;论文要强调**按独立任务/episode 的配对效应估计与不确定度**,不是显著格子计数。
- 采样限定**不自动是下界**:只取成功 episode 排除了记忆致败,但也提供了干净可达的状态使干预更容易成功;偏向方向不确定,
  称之为选择局限。1/337 是"打字值只在更早屏出现"这一狭窄现象的流行率,不是记忆关键性的流行率(更早的选择、身份、顺序、
  已完成子目标、视觉变化都可能重要)。
- **只看救回不能确立部署效用**:Δsuccess = p·r − (1−p)·h;Venus 保留文本时失败率 10%,30% 的救回只值 3 个点,打坏 3.3% 的原成功态就抵消。
  随机解码下还要加一个"重新解码一次 B=0"的对照(部分被筛出的失败会在另一次采样里自行消失)。

**新颖性比 STAMP vs MementoGUI 更宽**:A 面对 STAMP(程序化瞬态记忆依赖 + Memory-World)与 MemGUI-Bench(记忆密集任务、快照、
镜像任务对——但其镜像对针对跨任务迁移,**不固定当前观察去干预过去证据**,这是我们反事实设计可利用的区别)。B 面对 MementoGUI
(事件门控写入、按需情景检索、冻结底座、**已报告含控制器推理的延迟**——"冻结底座 + 选择性记忆"和"不计控制器的效率核算"都不是
可辩护的区分点)、**HiconAgent**(状态依赖的历史长度偏好含 {0,1,2},历史感知训练 + 压缩)、**GUIPruner**(历史图冗余的时间分辨率
分配与 token 剪枝)、AGMem(全图记忆减少某些错误同时加重另一些)。**不要把论文定位成发明记忆选择;定位成识别并利用"扣除文本中
已有记忆后视觉证据的增量价值"。**

**A 的最小决定性实验**:要回答的问题——**保留部署文本策略时,冻结 agent 能否用正确取回的非最近证据改善决策与后续任务结果**。
正在跑的三族 pilot 是对的载体,先别扩成大 benchmark。分离因果识别与部署验证:反事实孪生要同指令、同当前屏、同最近屏,只有更早
证据不同且要求不同正确决策;审计所有剩余输入通道的泄漏。**不要通过删掉相关事实来强制文本相同然后称之为原生部署**;部署验证让
agent 自己生成并保留正常轨迹——若它记下了事实且 B=0 成功,那是合法的记忆使用。在**全部预指定的记忆 checkpoint**(不只 B=0 失败的)
上跑干预矩阵:B=0 / recency-2 / 裁判选 2 帧 / **真实源帧(≤2)** / 匹配无关帧 / **反事实源帧交换**;固定当前图位置、历史图顺序、
分辨率、时间戳、提示脚手架;返回帧而非裁判写的解释;裁判可看整个已观察前缀但不得看未来帧、参考动作或隐藏标注。加一个便宜的
排障对照:把所需事实作为文本给出。**让"非连续"名副其实**:把唯一答案放在五屏之前会让 recency-2 按构造缺信息——oracle 能取回只是
sanity check;若主张非连续性,要有需要两个分离源屏的用例和更强的连续对照(如选定的两帧窗口、spaced/anchor+recent 基线);
否则用更准确的主张:**当历史图含当前上下文缺失的有用证据时,任务相关检索能胜过 recency**——"非连续"是检索集的性质,不是机理。
变化证据年龄、干扰项相似度、必要证据是否落在 recency-2 内;一个只因某任务族总在可识别步骤存答案而赢的选择器没学到有用检索。
**测后果而非仅参考动作一致**:报告两个孪生是否都做对、交换源证据后决策是否按正确方向改变;然后做带功能验证的 checkpoint 续跑
(不同但有效的恢复路径不算错;B=0 能导航回去取回事实就量它的额外动作与成本);最后在留出集上从头闭环、各策略自生轨迹。
规模与停机:go/no-go pilot 每族约 30–50 对独立实例化的孪生;确认样本由配对变异与最小效应决定。**以 Venus 为预指定主要消费者**
(已有历史图效用证据),Owl 作为重要的异质性结果,不平均成模糊标题。决定性结局:oracle 帧失败而 oracle 文本成功 ⇒ 瓶颈在
历史图消费;oracle 帧成功而裁判失败 ⇒ 存在值得解决的检索问题;裁判帧在原生文本下成功并改善续跑 ⇒ A 支持部署方向。
沉没 A 的东西:只有人工删轨迹后才有增益;把 oracle-only 成功当成可用选择器;平凡的"种答案"检索无泛化;动作匹配提升无功能后果。
严格的因果 benchmark 在方法失败时也可发表,但要以诊断贡献呈现。

**B 的最小决定性实验**:先证明有东西值得门控——B=0 ≥ recency-2 只说明"总是 recency-2"是差默认,不说明动态控制器有用;成功率
与总是 B=0 相同却多了检索成本的自适应方法是被支配的;成功的门控必须相对 B=0 **提升**成功率(或预指定的重要风险指标),且成本
低于总是附有用帧。先做 B_t ∈ {0,2} 二元决策。**门控要预测收益,不是预测失败或不确定**:目标 ≈ E[Y(取回帧) − Y(B=0) | 门控可见信息];
训练标签必须含中性与有害检索样本;门控只能用结果未知前的输入(当前观察、目标、保留轨迹、溯源元数据、维护的索引),
"在基线会失败时附帧"是 oracle 不是策略;需要预解码或第二次模型调用就计费。在**未筛选的闭环 episode**上评测(普通 MobileWorld +
A 的留出记忆关键 episode,分开报告;不要把难例藏在低流行率均值里,也不要看完结果再挑混合比例;组合主张要展示权衡随记忆关键
任务流行率的变化)。最少对照:总是 B=0、recency-1/2、总是选定帧、门控+选定帧、**同检索率的随机激活**(用同一选择器);
再跑门控+recency 帧(分离"何时取"与"取什么");加单帧基线。**全系统计费**:整 episode 成功率、历史与总视觉 token、总输入/输出、
端到端延迟(声明缓存配置);含门控推理、索引/记忆构建、检索、选择器图像处理、额外动作模型解码、错误导致的额外环境动作;
一次性与每步成本分开。扫全历史的裁判并没有让视觉计算消失。B=0 不是零视觉:按一当前 + 两历史等大估计,10% 步触发检索省 90%
历史图 token 但只省 60% 总输入图 token(未计控制器)。同一上下文上限、报实际消耗。**"同等成功"要有证据**:预先定非劣性边际;
示例:10% 配对不一致、2pp 边际、80% 功效、单侧 5%,真差为零时约需 **1,550 对 episode**——B 不自动是更便宜的论文。
沉没 B 的东西:总是 B=0 支配;计入选择器后增益消失;门控用了 oracle 标签或任务族捷径;同成本的随机激活一样好;"同等成功"靠宽区间。
"历史图可省略"的可复现发现可以支撑经验系统论文,但**不证明要加一个不必要的自适应控制器**。

**如何合并而不合并两个弱主张**:统一命题——**视觉历史的分配应取决于其相对 agent 已有文本记忆的增量决策价值,而不是 recency
或图像信息量本身**。三件事分开确立:信息可得性(更早截图含当前屏与文本都没有的证据吗)、消费者利用(这个冻结 agent 能用它改善
决策吗)、选择性部署(策略能否便宜地识别值得检索的时刻并改善成功–成本权衡)。A 立前两件,B 立第三件。Owl/Venus 对比有用
正因为"被判定有信息的证据未必对每个消费者有用"。最强论文 = 普通轨迹上的原生文本诊断 + 受控任务上的反事实证据测试 + 全成本
评估的在线预算策略;受控任务给可识别机制,普通任务防止策略变成"为奖励检索而造的 benchmark 的昂贵解"。**两个预算要分清**:
动作模型两帧上下文预算 ≠ 选择器搜索档案的总计算预算;A 可只研究前者,B 必须计后者。**不要把决策论框架本身当算法新颖性**;
贡献是识别协议、文本–图像替代与消费者异质性的证据、以及一个证明有用的策略。

**它会做的下一步**:先在现有 A pilot 里跑**原生文本 + 真实源帧**的干预——这是两条路之间最高价值的判别器。源帧在原生文本下
不帮忙 ⇒ 停止用更好的选择或更多布局 SFT 去拯救部署命题,可辩护的论文变成"视觉历史收益何时被文本记忆掩盖或受消费者限制",
B=0 是强基线而非发明门控的理由。源帧帮忙而裁判不帮 ⇒ 优先做检索。裁判帧在原生文本下帮忙并改善续跑 ⇒ 加二元门控,在未筛选
rollout 上测——这才是可信的 A+B。
